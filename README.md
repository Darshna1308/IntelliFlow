# IntelliFlow

## Intelligent Workflow & Approval Management Platform

IntelliFlow is a full-stack workflow and approval management platform designed to centralize document-driven requests, approvals, revisions, responsibilities, deadlines, and audit history.

## Status

🚧 Under Development

## Tech Stack

- React
- Vite
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Multer
- Docker

## Core Features

- Role-based authentication
- Workflow and approval management
- Document uploads
- Reviewer assignment
- Revision requests
- Audit trail
- Priority and overdue detection
- Analytics dashboards
